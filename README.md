# AudioBible

Web viewer and player for Reuben Institute's AudioBible — Reuben
Institute's styled scripture text (via StyledScriptures) with audio
playback, drawing on the `audiobible-*` recordings.

`audiobible-web` is a placeholder for now — the Flask app itself is not
yet implemented.
